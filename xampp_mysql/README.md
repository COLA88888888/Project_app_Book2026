# ຄຳແນະນຳການຕັ້ງຄ່າຖານຂໍ້ມູນ XAMPP MySQL (XAMPP MySQL Setup Guide)

ຄູ່ມືນີ້ຈະຊ່ວຍແນະນຳຂັ້ນຕອນການຕິດຕັ້ງຖານຂໍ້ມູນ MySQL ຢູ່ໃນ XAMPP ແລະ ການວາງໄຟລ໌ PHP API ເພື່ອໃຫ້ແອັບພລິເຄຊັນສາມາດເຊື່ອມຕໍ່ຂໍ້ມູນໄດ້.

---

## 📋 ຂັ້ນຕອນທີ 1: ເປີດ XAMPP Control Panel
1. ເປີດໂປຣແກຣມ **XAMPP Control Panel** ໃນຄອມພິວເຕີຂອງທ່ານ.
2. ກົດປຸ່ມ **Start** ຢູ່ຫຼັງ **Apache** ແລະ **MySQL** ເພື່ອໃຫ້ທັງສອງການບໍລິການເຮັດວຽກ (ປຸ່ມຈະປ່ຽນເປັນສີຂຽວ).

---

## 🗄️ ຂັ້ນຕອນທີ 2: ສ້າງຖານຂໍ້ມູນ ແລະ ນຳເຂົ້າໂຄງສ້າງ (Import SQL)
1. ເປີດ Web Browser ແລ້ວເຂົ້າໄປທີ່: [http://localhost/phpmyadmin/](http://localhost/phpmyadmin/)
2. ຄລິກທີ່ເມນູ **"New"** (ຢູ່ແຖບດ້ານຊ້າຍມື) ເພື່ອສ້າງຖານຂໍ້ມູນໃໝ່.
3. ປ້ອນຊື່ຖານຂໍ້ມູນວ່າ: **`edu_app`** ແລະ ເລືອກ Collation ເປັນ **`utf8mb4_unicode_ci`** -> ກົດປຸ່ມ **"Create"**.
4. ຄລິກເລືອກຖານຂໍ້ມູນ **`edu_app`** ທີ່ຫາສ້າງສຳເລັດ.
5. ຄລິກທີ່ເມນູ **"Import"** (ຢູ່ແຖບດ້ານເທິງ).
6. ກົດປຸ່ມ **"Choose File"** ແລ້ວເລືອກໄຟລ໌ **`schema.sql`** ທີ່ຢູ່ໃນໂຟນເດີ `xampp_mysql` ຂອງໂຄງການນີ້.
7. ເລື່ອນລົງລຸ່ມສຸດ ແລ້ວກົດປຸ່ມ **"Import"** (ຫຼື "Go") ເພື່ອສ້າງຕາຕະລາງທັງໝົດອັດຕະໂນມັດ.

---

## 📂 ຂັ້ນຕອນທີ 3: ວາງໄຟລ໌ PHP API ໃນ XAMPP htdocs
1. ສ້າງໂຟນເດີໃໝ່ຊື່ວ່າ **`app_book`** ໄວ້ພາຍໃຕ້ Directory: `C:\xampp\htdocs\`
   - ທີ່ຢູ່ປາຍທາງຈະເປັນ: **`C:\xampp\htdocs\app_book\`**
2. ກັອບປີ້ໄຟລ໌ **`api.php`** ທີ່ຢູ່ໃນໂຟນເດີ `xampp_mysql` ຂອງໂຄງການນີ້ ໄປວາງໄວ້ໃນໂຟນເດີທີ່ຫາກໍ່ສ້າງ.
   - ທີ່ຢູ່ໄຟລ໌ຈະເປັນ: **`C:\xampp\htdocs\app_book\api.php`**

---

## 🧪 ຂັ້ນຕອນທີ 4: ທົດສອບການເຊື່ອມຕໍ່ API
ທົດລອງເຂົ້າເວັບໄຊທ໌ນີ້ໃນ Browser ເພື່ອກວດສອບການເຊື່ອມຕໍ່:
👉 [http://localhost/app_book/api.php?action=read_all_users](http://localhost/app_book/api.php?action=read_all_users)

- ຖ້າຂຶ້ນຂໍ້ຄວາມວ່າງ `[]` ຫຼື ຂໍ້ມູນຜູ້ໃຊ້ ໝາຍຄວາມວ່າ **ການເຊື່ອມຕໍ່ຖານຂໍ້ມູນ XAMPP MySQL ສຳເລັດແລ້ວ!** 🎉
